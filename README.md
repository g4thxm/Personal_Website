# 🌐 Personal Website

A modern, responsive personal portfolio website showcasing my projects, technical skills, certifications, and experience as a Full-Stack Developer.

🔗 **Live Demo:** https://gauthamk.netlify.app

---

## 📖 About

This repository contains the complete source code for my personal portfolio website. It serves as a central place to showcase my projects, certifications, technical skills, and professional journey.

The website is designed with a clean, responsive interface and focuses on performance, accessibility, and SEO best practices.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/g4thxm/Personal_Website.git
```

### Navigate into the project

```bash
cd Personal_Website
```

### Run locally

Simply open `index.html` in your browser.

Or use a local server, for example:

```bash
python -m http.server 8000
```

Then visit:

```
http://localhost:8000
```
